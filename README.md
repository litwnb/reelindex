# Reelindex

> Minimalistic, user-friendly movie indexing project with features such as: finding films by titles, director or genre, giving ratings, personal watchlist and more.

## 📌 Overview

**Reelindex** is a RESTful Spring Boot web service developed to help movie enthusiasts conveniently navigate through a list of the best films from around the world, find something just for themselves, rate it on a scale from 1 to 10 stars or save for a later watching.

The application was built as a portfolio project to demonstrate practical skills in software development from scratch to a ready-to-use solution, application architecture, and the use of modern technologies.

## 🛠️ Technology Stack

### Backend

-   **Java 17** — Main programming language.
    
-   **Spring Boot** — Backend application framework.
    
-   **MySQL** — Data persistence.
    
-   **Hibernate** — ORM database interaction.
    
-   **Spring Security** — Authentication and authorization.

-   **Project Lombok** — API for automatic generation of boilerplate code.

-   **Mapstruct** — API for quick DTOs mapping.
    

### Frontend

-   **HTML5** — Application structure.
    
-   **CSS3 / Tailwind CSS** — Styling and layout.
    
-   **JavaScript** — Client-side functionality.
    

### Tools & Technologies

-   **Git** — Version control.
    
-   **GitHub** — Source code hosting.

-   **Docker** — Containerization and deployment.

-   **Render** — Hosting of a deployed project.

-   **Aiven** — Database hosting.
    
-   **Maven** — Project build and dependency management.
    
-   **Intellij IDEA** — Development environment.
